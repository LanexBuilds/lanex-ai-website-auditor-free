# Email Auto Responder Template

This template reads incoming emails via IMAP and automatically sends a pre-defined response.

## Requirements

* **IMAP Credentials:** You need the IMAP server details, username, and password for the email account you want to monitor.
* **SMTP Credentials:** You need the SMTP server details, username, and password to send the automated response.

## How to Import

1. Copy the contents of `workflow.json`.
2. Open your n8n workspace.
3. Click "Add Workflow".
4. Click the gear icon in the top right, then select "Import from Clipboard" (or press Cmd/Ctrl + V on the workflow canvas).
