# AI Sentiment Analyzer

This simple n8n micro-template accepts text via a webhook, analyzes its sentiment using OpenAI, and returns 'Positive', 'Negative', or 'Neutral'.

## Requirements
*   OpenAI API Key configured in n8n.

## How to Import
1. Copy the contents of `workflow.json`.
2. In n8n, go to your workspace.
3. Paste the contents directly into the workflow canvas.
4. Set up your OpenAI credentials in the OpenAI node.
