# Slack Daily Reminder

This simple n8n micro-template sends a predefined reminder message to a specific Slack channel every day.

## Requirements
*   Slack API credentials configured in n8n.

## How to Import
1. Copy the contents of `workflow.json`.
2. In n8n, go to your workspace.
3. Paste the contents directly into the workflow canvas.
4. Set up your Slack credentials in the Slack node and specify the desired channel and message.
