# Slack Daily Message Template

This template posts a daily message to a specified Slack channel.

## Requirements

* **Slack Credentials:** You need a Slack app token or OAuth credentials configured in n8n.

## How to Import

1. Copy the contents of `workflow.json`.
2. Open your n8n workspace.
3. Click "Add Workflow".
4. Click the gear icon in the top right, then select "Import from Clipboard" (or press Cmd/Ctrl + V on the workflow canvas).
